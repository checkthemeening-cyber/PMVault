# _templates ― 雛形と規約

| ファイル | 用途 |
|---|---|
| [[命名と4手がかり]] | 命名・frontmatter・タグの基本規約 |
| [[wikiページ_テンプレ]] | 概念・人物などの常設ページ |
| [[議事録_テンプレ]] | 打ち合わせ記録（4手がかり付き） |
| [[リサーチノート_テンプレ]] | 出典付き調査 |
| [[人物_テンプレ]] | 20_案件/entities/ の人物 |
| プロンプトテンプレート集 | よく使う頼み方 |
| [[MOC_テンプレ]] | テーマの俯瞰地図（MOC）を量産する雛形 |
| [[提案ストーリー_テンプレ]] | 提案の骨格（SCQA＋ピラミッド＋空雨傘＋アクションタイトル） |
| [[参考ストーリーメモ_テンプレ]] | 見聞きした提案のストーリーを型として貯める（公開情報のみ） |
| [[例え話パターン_テンプレ]] | 例え話を1件1ノートで貯める（マッピング＋崩れる点＋出典） |
| [[業界プロファイル_テンプレ]] | 1業界1ノートの常設プロファイル（論点/KPI/規制/取り組み） |
| [[事例カード_テンプレ]] | 1事例1カード（成熟度・一次情報URL・確からしさ付き） |
| [[動向スナップショット_テンプレ]] | 四半期の動向・規制更新を時系列で残す |
| [[案件プロファイル_テンプレ]] | 20_案件/engagements/ の案件1枚（初日に開く） |
| [[フレームワーク_テンプレ]] | 00_ナレッジ/frameworks/ の分析フレーム1枚（いつ使う/入力/出力/落とし穴） |
| [[ステークホルダーマップ_テンプレ]] | 案件の意思決定者と影響力マップ |
| [[ベンチマーク_テンプレ]] | 00_ナレッジ/benchmarks/ の再利用する数値1件 |
| [[プレイブック_テンプレ]] | 00_ナレッジ/plays/ の進め方の型 |
| [[インタビュー記録_テンプレ]] | 専門家・顧客ヒアリング（逐語と解釈を分離） |
| [[意思決定ログ_テンプレ]] | 確定した意思決定1枚 |
| [[出所と確からしさ_テンプレ]] | 信頼レイヤーfrontmatter拡張（出所/確からしさ/鮮度/更新責任） |
| [[レビュー記録_テンプレ]] | 週次/月次レビューの記録雛形 |

命名は `YYYY-MM-DD-種類-主題.md`（日付ノート）＋ frontmatter（type/status/date/topic/tags）で統一。

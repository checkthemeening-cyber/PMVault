# 出所と確からしさ（信頼レイヤーの拡張仕様）

要約：既存の4手がかりを壊さず、AI参照用ノートにのみ信頼レイヤーを追加する仕様。ノートの鮮度と確からしさを明示し、古い情報が引用されるリスクを抑えることを目的とする。[[命名と4手がかり]] の補足。

## 前提（壊さない）
type / status / date / topic / tags は全ノート必須のまま変えない。下記はclaim系ノート（主張・意思決定・取り込み資料・AI生成）にだけ任意で足す。雑メモには付けない。

## 信頼レイヤーのfrontmatter記入例
~~~
certainty: 有力        # 確実 / 有力 / 仮説 / 未確認（AI生成は既定で仮説、人手確認後に certainty を引き上げる）
source: https://...   # 一次URL or 内部資料名 or AI生成
author: 協働          # human / AI / 協働
last_verified: 2026-07-01   # 最終の人手確認日
review_by: 2026-10-01       # 次回見直し期日
owner: Nao           # 更新責任者（[[OWNERS]]と対応）
公開区分: 公開        # 公開 / 社内（ADLは公開のみ。公開以外はingest時に弾く）
~~~
最小セットは certainty、source、last_verified、owner の4項目。author・review_by・公開区分は必要に応じて足す。

## 陳腐化しきい値（種別 × 許容鮮度）
| 文書種別 | 許容鮮度 |
|---|---|
| コンプラ・価格 | 即時（0） |
| 手順・仕様 | 24時間 |
| 参照・標準 | 30日（運用上の中間値。下記Atlanには0/24h/90日のみ明示） |
| 背景・経緯 | 90日 |

review_by を過ぎたノートはレビュー待ちに落とす。研修Vaultはこの簡略運用で十分。自動の鮮度スコアリングは対象外とする。

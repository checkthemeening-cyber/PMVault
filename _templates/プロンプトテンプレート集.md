# プロンプトテンプレート集

## 蓄積・更新
- 取り込み: 「`30_インプット/.raw/` の資料を ingest して。要点を概念・人物・出典に分け、4つの手がかりを付けて index も更新して」
- 会話保存: 「いまの話を save して。決定事項と直近のアクションを残し、関連ページにリンクして」
- 自律調査: 「`<テーマ>` を autoresearch して。公開情報のみ、主張に出典URLと日付を添えて sources に貯めて」
- 点検: 「lint して。孤立ノート・リンク切れ・手がかりの抜けを重要度順に出して」

## 引き出す
- 時系列: 「この案件について、過去に決めたことを時系列で出して。根拠ノートも添えて」
- 論点抽出: 「`<相手>` との過去のやり取りで、価格に関する論点だけ拾って」
- 状態で絞る: 「`<テーマ>` の、進行中のノートと保留中のノートを分けて見せて」
- 食い違い: 「半年前の分析と今週のメモで、食い違っている点はある?」

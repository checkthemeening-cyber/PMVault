# 命名と4つの手がかり（このVaultの基本規約）

AIがノートを引き出せるよう、すべてのノートに4つの手がかりを持たせる。

## 4つの手がかり
- type … 種類（会議録 / 提案 / 調査 / 意思決定 / 顧客メモ / 概念 / 人物）
- when … 時期（作成日・関連時期）
- topic … 主題（案件名・取引先・テーマ）
- status … 状態（進行中 / 完了 / 保留 / 参照用）

## 命名の型（日付ノート）
~~~
YYYY-MM-DD-種類-主題.md
例:
2026-05-20-会議録-新規事業レビュー.md
2026-05-18-提案-A社向け運用改善.md
2026-04-28-意思決定-来期予算方針.md
~~~
日付を先頭に置くと時系列に並ぶ。時期での絞り込みが効き、名前の衝突も起きない。概念・人物の常設ページは主題名でよい（例 `00_ナレッジ/concepts/仕様駆動開発.md`）。

## frontmatter（全ノート冒頭）
~~~
---
type: 会議録
status: 進行中
date: 2026-05-20
topic: 新規事業
tags: [新規事業, A社, 投資判断]
---
~~~
種類ごとに項目を足してよい（提案なら deadline/priority、意思決定なら decided/decision、顧客メモなら company/next_action）。

## タグの付け方
- `topic` は主題、`status/進行中` は状態、`project/A社案件` は案件。「/」で階層化
- 5個以上のノートで使うものだけ作る（増やしすぎない）

## 引き出しの効き目
status を持たせると「進行中だけ」「完了を除く」で絞れる。引き出しで最も効くのが status だ。

# PMVault ― 第二の脳（スターター）

人間とAIで蓄積するObsidian Vaultのスターターです。AIを第一の読み手として設計してあり、蓄積と引き出しの両方をこの1つで扱います。Obsidianでこのフォルダを開き、ターミナルでこのフォルダへ `cd` して `claude` を起動します。左にObsidian、右にターミナルの2画面で使います。

## まず読むファイル
- `WIKI.md` … このVaultの運用ルール（4つの手がかり・取り込みループ・引き出し方）
- `index.md` / `40_運用/hot.md` … 何がどこにあるか／直近の文脈
- `40_運用/persona.md` / `40_運用/domain.md` … AIの人格／私の情報

## 最初にやること
1. **まず `/setup` を実行**します。あなたの環境（Vaultの場所・名前・OS）に合わせて初期設定し、命令ログHookも自動で登録します（最初の1回だけ）
2. `/wiki` でVaultの骨格を整える
3. `30_インプット/.raw/` の練習用メモを `ingest` する → wikiページが生成される
4. `「いま取り込んだ件について何を知ってる?」` と聞いて、出典付きで過去の判断が返るか確かめる

## 蓄積・引き出し
- 蓄積: `30_インプット/.raw/` に資料 → `ingest` ／ 会話 → `/save` ／ 調べ物 → `/autoresearch` ／ 点検 → `lint`
- 引き出す: 自然な言葉で「あの案件の過去の判断を時系列で出して」
- 人間から: `/intake` `/interview`

調査からレポート・スライド作成は、別の演習プロジェクトフォルダ（演習_A社案件）で進めます。

2つのフォルダは、それぞれで `claude` を起動してセッションを持ち、`claude agents` で AgentView を開いて行き来します。

# exercise（Day1・Vaultに知識を蓄積する）

Day1は、このVaultを第二の脳として使える形に整える日です。調査から提案の演習はDay2、別フォルダの `演習_A社案件/` で行います。

進行の読み物はハンズオンHTML、答え合わせの中身は `_研修/hints/`、順番と達成基準はこの `_研修/exercise/` にあります。

## 進め方（全HO共通）
各HOは4段で進みます。

1. 考える：`_研修/memo.md` にHOの見出しで予想を書く
2. 書く：Claude Code（ターミナル）に自分の言葉で指示を書く
3. 実行：指示を実行し、Obsidianでノートや `40_運用/log.md` を開いて結果を見る
4. 答え合わせ：`_研修/hints/stepNN_*.md` を開き、自分の指示と比べる

参考プロンプトは `_研修/exercise/` には載せていません。自分で書いてから `_研修/hints/` を開きます。作業フォルダはこのPMVault。詰まったら、まず `cd ~/Documents/PMVault` で起動しているか確認します。

## 早く終わった方向け（独立課題）
`_extra_challenge.md` … 各HOの発展課題を終えた方向けに、HOの順番と切り離して取り組める課題を用意しています。自分の業務テーマで仕組みを1周まわす課題と、Vaultの点検・検索の課題です。参考解はそれぞれの `_研修/hints/` で誘導します。

# Day1 HO06：save-setup で実績化・Day2への布石

## ねらい
今日Vaultで効いた設定（persona・domainの抜粋・使ったSkill・うまくいった頼み方）を実績として残します。Day2は別フォルダで作業するので、ここで保存しておくと `/load-setup` で同じ設定を持ち込めます。Day1の締めにあたり、今日の状態をDay2で再現できる形にすることを目指します。

## 使うもの
| 項目 | 内容 |
|---|---|
| 作業する場所 | Claude Code（ターミナル）で指示。結果はObsidianで `_実績` を開いて確認 |
| 対象ファイル | `40_運用/persona.md`、`40_運用/domain.md`、`40_運用/log.md`、使ったSkill、`_研修/_実績/INDEX.md` |
| 成果物 | `_研修/_実績/<案件名>/` に設定一式、`_研修/_実績/INDEX.md` に1行追記 |
| 目安時間 | [10min] |

## 進め方
1. 考える：次の案件で今日と同じ動きを再現するには、何を保存すべきか（persona・効いた頼み方・Skill構成）。`_研修/memo.md` にHO06の見出しで予想します。
2. 書く：`/save-setup` に渡す指示を書きます。案件名、保存する範囲、`40_運用/log.md` から選ぶ「効いた頼み方」を伝えます。
   - 注意：日付は自動で入りません。保存日は自分で指定します。
   - Tips：`40_運用/log.md` の全部を貼らず、結果が良かった命令だけを選びます。
3. 実行：`/save-setup` を実行します。Obsidianで `_研修/_実績/<案件名>/` と `_研修/_実績/INDEX.md` を開いて中身を見ます。
   - 注意：機密や固有の生々しい情報は入れません。命令文に混じっていたら伏せます。
4. 答え合わせ：`_研修/hints/step06_savesetup_hint.md` を開き、残す粒度と注意点を確認します。

## 自分で考えるポイント
- 後で読んだ自分（や同僚）が、その時の頼み方を再現できる粒度になっているか
- INDEXの1行に、どんな用途で効いたかが書けているか

## 達成チェック
- [ ] `_研修/_実績/<案件名>/` に設定一式（persona写し・domain抜粋・Skill一覧・効いた頼み方）が保存されている
- [ ] `_研修/_実績/INDEX.md` に1行追記されている
- [ ] 保存日が自分で指定した日付で入っている
- [ ] Day2で `/load-setup` の対象にできる状態になっている

## うまくいかないとき
- `_実績` にフォルダができない、またはINDEXが更新されない → 案件名と保存日が渡っていない場合があります。明示して頼み直します。

~~~
/save-setup を実行してください。案件名は「Day1 Vault構築」、保存日は 2026-07-XX です。
persona の写し、domain の効いた抜粋、使った Skill 一覧、log.md から選んだ効いた頼み方3つを
_研修/_実績 に保存し、_研修/_実績/INDEX.md にも1行足してください。
~~~

- それでも直らないとき：ハンズオンHTMLの「詰まったときの即応」、`_研修/hints/step06_savesetup_hint.md`

## 発展課題（早く終わった方向け）
1. 効いた頼み方の実績添付
   - 背景：頼み方を実績に添えると、Day2で `/load-setup` したとき命令ごと再現できます。
   - 条件：`40_運用/log.md` から選ぶ。固有の機密が混じる命令は伏せる。既存の実績は消さない。
   - 対象ファイル：`40_運用/log.md`、`_研修/_実績/<案件名>/`
   - 実行すること：`40_運用/log.md` から効いた頼み方を3つ選び、なぜ効いたかを一言添えて実績に足す。
   - 考える要素：3つを選ぶ基準は何か（結果の良さ／再利用しやすさ／テーマの広さ）。
   - ヒント：命令文だけでなく、その命令が向いていた場面も一言残すと、あとで読み替えやすくなります。
   - 達成条件：実績に「効いた頼み方3つ＋各1行の理由」が保存されている。
   - 参照：`_研修/hints/step06_savesetup_hint.md` の「発展課題の参考解」

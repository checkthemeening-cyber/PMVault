# Day1 HO05：ログHook の登録と振り返り

## ねらい
Claudeへの命令を毎回手で控えるのは続きません。命令が自動で `40_運用/log.md` に残る設定を入れて、後から頼み方を振り返れるようにします。効いた頼み方が分かれば、personaや実績に反映して次から再利用できます。Day1の蓄積する工程で、HO01のあとならいつ着手してもかまいません。

## 使うもの
| 項目 | 内容 |
|---|---|
| 作業する場所 | Claude Code（ターミナル）で設定と命令。結果はObsidianで `40_運用/log.md` を開いて確認 |
| 対象ファイル | `_研修/_setup/01_ログHookをClaudeユーザー設定に登録.md`、`~/.claude/settings.json`、`40_運用/log.md` |
| 成果物 | `40_運用/log.md` に、日付・時刻・カテゴリ付きの命令行が追記される |
| 目安時間 | [15min] |

## 進め方
1. 考える：このHookはDay2の別フォルダ（演習_A社案件）の命令も拾いたい設定です。プロジェクト個別ではなくClaudeのユーザー設定に入れる理由を、`_研修/memo.md` にHO05の見出しで予想します。
2. 書く：`_研修/_setup/01_ログHookをClaudeユーザー設定に登録.md` の手順どおり、`~/.claude/settings.json` の `UserPromptSubmit` にHookを登録します。
   - 注意：Vaultが `~/Documents/PMVault` 以外の場所なら、commandの前に `OBSIDIAN_VAULT="..."` でVaultの場所を渡します。
   - Tips：`/setup` を実行済みなら、このHookは登録されています。この演習は手動で確認・設定する場合の手順です。
3. 実行：Claude Codeを再起動し、命令を数回出します。Obsidianで `40_運用/log.md` を開き、行が増えるのを見ます。
   - Tips：記録されるのは命令の本文だけです。長い命令は先頭500文字までに切られます。
4. 答え合わせ：`_研修/hints/step05_loghook_hint.md` を開き、確認の仕方とつまずきの対処を見ます。

## 自分で考えるポイント
- 命令のカテゴリ（調査／作成／修正／引き出し／その他）は、どんな言葉で振り分けられていそうか
- 1日分の命令を眺めると、自分の頼み方にどんな癖が見えるか

## 達成チェック
- [ ] `~/.claude/settings.json` の `UserPromptSubmit` にHookが登録されている
- [ ] Claude Code再起動後の命令が `40_運用/log.md` に追記されている
- [ ] 各行に日付・時刻・カテゴリ・命令本文が並んでいる

## うまくいかないとき
- `40_運用/log.md` に何も増えない → Vaultの場所がずれています。`OBSIDIAN_VAULT` に自分のVaultの絶対パスを渡し直します。

~~~
~/.claude/settings.json の UserPromptSubmit フックの command を見てください。
私のVaultは <ここに絶対パス> です。OBSIDIAN_VAULT とスクリプトのパスがこのVaultを指しているか確認して、直す案を出して。
~~~

- それでも直らないとき：ハンズオンHTMLの「詰まったときの即応」、`_研修/hints/step05_loghook_hint.md`

## 発展課題（早く終わった方向け）
1. 効いた頼み方のpersona反映
   - 背景：うまくいった頼み方は、personaに書けば次から毎回効きます。記録を活用に変える1周です。
   - 条件：`40_運用/log.md` の既存の記録を消さない。personaは差分で確認してから反映する。
   - 対象ファイル：`40_運用/log.md`、`40_運用/persona.md`
   - 実行すること：1日分の `40_運用/log.md` を読み、結果が良かった命令を3つ選び、共通する頼み方を `40_運用/persona.md` に反映する。
   - 考える要素：命令文そのままでなく、どう一般化すればほかのテーマでも効くか。
   - ヒント：`/tune-persona` を使うと、反映内容を対話で詰められます。
   - 達成条件：選んだ3命令の共通点が、personaの応答方針として1〜2行で書けている。
   - 参照：`_研修/hints/step05_loghook_hint.md` の「発展課題の参考解」

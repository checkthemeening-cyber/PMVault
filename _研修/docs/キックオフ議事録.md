# キックオフ議事録 ― A社（架空・産業用モーターメーカー）生成AI構想

> 研修用の架空の打ち合わせ記録です（架空）。固有名詞・数値はすべて架空。

- 日付：本社3F 会議室
- 出席（ADL）：佐倉 健（パートナー）、三宅 由佳（マネージャー）
- 出席（A社・架空）：大滝 義信（経営企画担当 常務）、林田 美咲（経営企画部 課長）、渡会 亮（情報システム部 部長）
- 目的：生成AI全社活用構想の進め方すり合わせ、論点の洗い出し

## やり取り

大滝常務の話。現場で生成AIを試す動きはこの1年で急に増えた。設計、調達、品質、間接部門と、部署ごとに勝手に始まっている。ただ全社の方針がないので、どこに投資すべきか経営として判断できない。半年で意思決定までは持っていきたい。

林田課長の補足。PoCは10件近く動いているが、続けるべきか止めるべきかを決める物差しがない。効果が出ているのか、なんとなくでしか語れない。ここを先に決めないと前に進めない。

渡会部長の懸念。設計図や原価のデータは社外に出せない。情報管理の規程もまだ生成AI向けには整っていない。現場が便利だからと勝手に使い始めていて、止めるに止められない状態もある。

大滝常務の要望。まずは外がどこまでやっているか知りたい。同業や先進的な製造業が、生成AIで何を、どの業務で、どこまでやっているのか。公開されている範囲で構わないので俯瞰したい。そのうえで、うちは何から手を付けるべきかの順番を示してほしい。

三宅マネージャーの確認。御社の内部データには触れず、公開情報の動向と事例を整理する形で進めます。そこから打ち手の優先順位を組み、経営会議にかけられる粒度の資料にまとめます。

佐倉パートナーのまとめ。論点は、製造業での生成AIの活用実態、PoCを本番化した企業の体制と効果測定、情報管理の設計。この3つを公開情報で押さえ、A社としての優先順位に落とす。次回までに動向の初版を持ってくる。

大滝常務の最後の一言。資料は経営会議にそのままかけられる粒度で。細かい技術論より、何から始めて何が変わるのかが伝わるものにしてほしい。

## 決まったこと
- ADL側は公開情報のみでリサーチする。クライアント内部データは扱わない
- 論点は3つ（活用実態 / 本番化の進め方 / 情報管理）
- 成果は経営会議にかけられる粒度の提案資料
- 半年で意思決定、本格投資は来期から

## 次のアクション
- 製造業の生成AI活用の動向と事例を、出典付きで初版にまとめる
- そこから「何から手を付けるか」の優先順位の仮説を立てる

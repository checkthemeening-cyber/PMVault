# ハンズオンテーマと進め方

## 題材
架空クライアント「A社（架空）」から、生成AIの全社活用構想づくりを相談された、という設定です。あなたはADLのパートナーとしてこの案件にアサインされ、2日間で公開情報のリサーチから提案スライドの初版までを組み上げます。

詳しい前提は [[案件ブリーフィング_A社]]、相談の経緯は [[キックオフ議事録]] にあります。

## なぜこの題材か
コンサルタントの実務に近いからです。クライアントは「他社や先進製造業が、生成AIで何をどこまでやっているのか、公開情報で俯瞰したい」と言っています。手元の機密データではなく、外部の動向と事例を一次情報で押さえ、そこから打ち手の優先順位を組む。公開情報を一次情報で押さえ、Vaultに整理していく作業は Claude Code × Obsidian と相性がよいです。

## 2つのフォルダで進める
- このVault（チーム共通の第二の脳）… 知識の蓄積・整理とAI設定の書き換えを担う側。Day1の中心
- 別フォルダ 演習_A社案件 … 調査からレポート、提案スライドまでを作る側。Day2の中心

各フォルダで `claude` を起動してセッションを持ち、`claude agents` で AgentView（複数のClaude Codeセッションを一覧・切り替える表示モード。ハンズオン資料の「画面構成」を参照）を開いて行き来します。Day1で整えた設定は、Day2の冒頭に /load-setup で演習プロジェクトへ持ち込みます。

## 2日間で作る成果物
- Day1（Vault）：persona/domain を案件に合わせて書き換え、知識をintake/interviewで貯め、lintで整え、ログHookを入れ、今日の設定を _研修/_実績 に保存
- Day2（演習プロジェクト）：公開情報の調査ノート → 4層レポート → スライドプラン → 提案スライド初版（PPTX）
- Day2終わり：有効だった設定を /save-setup でVaultへ還元

## 公開情報だけで進める理由
どちらのフォルダにも公開情報しか入れません。今回の題材も、クライアントの内部資料は一切使わず、市場動向・他社事例・技術トレンドだけでリサーチします。A社は架空の会社なので、そもそも内部データは存在しません。実案件でも同じで、外に出せない情報を持ち込まない運用をそのまま体験します。

## 進め方
各ハンズオンの順番と達成基準は、Day1はこのVaultの _研修/exercise/、Day2は演習プロジェクトの exercise/ を見ます。参考プロンプトはどちらも _研修/hints/ にあります。

# hints（Day1・答え合わせ）

各ハンズオンで自分のプロンプトを書いたあとに開きます。先に開くと考える機会が減ります。

各stepには、参考プロンプト・仕組み・比較観点・よくある勘違いに加えて、その回の発展課題の参考解（参考プロンプトと期待される成果の形）が末尾に入っています。発展課題まで進んだ方が確認する場所です。

| step | 対応HO | 発展課題の参考解 | ファイル |
|---|---|---|---|
| step01 | HO01 persona/domain | あり | `step01_persona_hint.md` |
| step02 | HO02 intake/interview | あり | `step02_intake_hint.md` |
| step03 | HO03 organize | あり | `step03_organize_hint.md` |
| step04 | HO04 lint（点検） | あり | `step04_sync_hint.md` |
| step05 | HO05 ログHook | あり | `step05_loghook_hint.md` |
| step06 | HO06 save-setup | あり | `step06_savesetup_hint.md` |

`_研修/exercise/_extra_challenge.md` の独立課題は、自分のテーマや判断で進める課題のため、参考解を用意していません。各工程の参考プロンプトは対応するstepを見てください。

## 2026-07-17
- **nikkei-news HTML パーサー修正 第1段階**
  - 問題：記事 URL の正規表現が旧形式（`/article/XXX`）を想定 → 新形式（`/prime/mobility/article/XXX`）が取得できず、記事数 0 件
  - **修正1：カテゴリページの記事 URL 抽出**
    - 修正前：`r'href="(https://www\.nikkei\.com/article/[^"]+)"'`
    - 修正後：`r'href="(https://www\.nikkei\.com/[^"]*?/article/[^"]+)"'`（中間パスに対応）
  - **修正2：/prime/ パス記事のタイトル抽出**
    - セレクタを拡張：`["title_t3guga0", "index-module*", "cmn-article-title"]`
    - `/prime/` 記事は `<h1 class="index-module__-28Xya__title">` を使用
  - **修正3：/prime/ パス記事の本文抽出**
    - セレクタを拡張：`["body_*", "article-body", "paragraph-node-module*", "article-section-module*"]`
    - `/prime/` 記事は `<div class="paragraph-node-module__9ZOjZa__paragraph">` または `<article class="article-section-module__ek6Sia__snippet">` を使用
  - 検証結果：タイトル・本文が正常に取得されるが、**すべてのカテゴリから同じ 2 件の記事が抽出される問題が発覚**

- **nikkei-news HTML パーサー修正 第2段階（重複記事を解決）**
  - 問題：カテゴリページのリンクに「相対パス `/article/XXXXX/`」と「絶対 URL `https://www.nikkei.com/article/XXXXX/`」の 2 形式が混在
  - **修正4：相対パスリンクの抽出と正規化**
    - カテゴリページから `href="/article/XXXXX/"` 形式のリンクを抽出
    - 相対パスを絶対 URL に変換
    - 既存の絶対 URL リンクと統合し、重複排除（`dict.fromkeys()` で実装）
  - 「すべてのカテゴリに同じ記事」問題は**完全に解決**

- **nikkei-news 本文抽出機能を実装**
  - 問題：タイトルは取得できるが、本文が取得できていない
  - **原因分析**：HTMLパーサーで `body_*` や `article-body` クラスを探していたが、該当する div には小さいテキストしかなく、実際の本文は段落 p タグに分散
  - **修正5：BeautifulSoup で p タグから直接本文抽出**
    - 20文字以上のテキストを含む p タグを採用
    - HTMLパーサーの複雑性を排除し、シンプルで堅牢な実装に統一
  - **検証結果**
    - 各カテゴリから 22 件の異なる記事を取得（重複排除により 42 件 → 22 件）
    - 記事タイトル + 公開日時 + 本文をすべて正常に抽出
    - 例）「WHERE 月面技術で7300万物件を可視化」の記事：「衛星データから空き地を探す新興のWHERE...」（本文が正常に表示）

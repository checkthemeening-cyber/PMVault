# overview ― このVaultの概要

このVaultは公開情報のリサーチと案件ナレッジを、AIが引ける形で蓄積する。

- 主な用途: 公開情報の調査・整理・ストーリーライン・提案資料づくり
- 広げると: 業界プロファイル・事例・ベンチマーク・案件・フレームワーク・提案の型・例え話まで、コンサルで毎日引く層を貯められる（[[index]] のサブ索引と [[WIKI]] の『広げる』参照）
- 進め方: ソースを 30_インプット/.raw/ → ingest で wiki 化 → 自然言語で引き出す

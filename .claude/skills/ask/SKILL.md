# ask ― 引き出す（要約でなく筋を返す）

「しまったもの」を、4つの手がかりで絞り込んで引き出します。

## やること
1. `40_運用/hot.md` → `index.md` → 関連ページ の順に、必要な分だけ読む（全ページは読まない）
2. 4つの手がかりで絞る：type（種類）/ when（時期）/ topic（主題）/ status（状態）
   - 例「進行中の・新規事業の・先月以降の・意思決定を」→ status=進行中 & topic & date & type で絞る
3. 浅い目次要約で終えず、「いつ何を決めたか」の筋（時系列・論点・食い違い）を組み立てる
4. 必ず根拠ノート（`[[元ノート]]`）を添える。曖昧なら「該当が見つからない」と正直に言う

## うまく引き出せないとき
- 手がかりが足りないノートが原因。`lint` で抜けを洗い、命名・frontmatterを足す（[[命名と4手がかり]]）

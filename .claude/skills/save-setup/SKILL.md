# save-setup ― 効いた設定を実績として残す

ある案件で良い結果が出た設定を、次の案件で再現できるよう保管します。

## やること
1. 案件名を確認する（無ければ尋ねる）
2. `_研修/_実績/<kebab-案件名>/` を作り、次を保存する
   - `40_運用/persona.md` の写し
   - `40_運用/domain.md` のうち、その案件に効いた抜粋
   - 使った Skill / Subagent の一覧（名前と一言）
   - うまくいった頼み方（実際の命令文を2〜5個。logs/ から拾ってよい）
   - 向いていた用途・注意点
3. `_研修/_実績/INDEX.md` の表に1行追記する（案件・保存日は人間に確認、効いた設定・用途・フォルダ）

## 注意
- 日付は人間に聞く（このVaultでは自動の現在時刻を使わない方針のため）

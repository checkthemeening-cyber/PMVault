# update-domain ― 40_運用/domain.md の更新

`40_運用/domain.md` を最新に保ちます。会話の中で人間について新しく分かったことを、該当の節に反映します。

## やること
1. 直近のやり取りから、40_運用/domain.md に効く事実を拾う（役職・担当・ツール・判断基準・目標・好み・嫌う進め方）
2. 既存の記述と照らし、追記か更新かを判断する。古い記述は上書きする
3. 変更点を一覧で見せて、承認を得てから書き込む
4. `updated` を人間に日付確認して入れる

## 効かせ方
- 次回以降、応答前に 40_運用/domain.md を読み、文体・粒度・判断基準の設定を参照する（CLAUDE.md の指示どおり）
- 判断基準や目標は資料の構成や提案の切り口に効くので、優先して拾う

## 注意
- 憶測で人物像を作らない。会話で出た事実だけを書く
- 機微な個人情報は書かない（業務に効く範囲にとどめる）
- 勝手に大きく書き換えない。差分承認制

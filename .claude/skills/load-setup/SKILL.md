# load-setup ― 過去の設定を今に再現する

`_研修/_実績/INDEX.md` から似た案件を選び、その設定を今の作業に適用します。

## やること
1. `_研修/_実績/INDEX.md` を読み、候補を提示する。用途が近いものを推す
2. 選ばれた案件フォルダの persona・頼み方・Skill構成を読む
3. 適用方法を提案する
   - `40_運用/persona.md` に取り込むか（上書きでなく差分で確認）
   - 使う Skill / Subagent を今の案件用に読み替える
   - 効いた頼み方を、今の案件の言葉に置き換えて提示する
4. 人間の承認を得てから反映する

## 注意
- いきなり上書きしない。差分を見せて承認を取る
- 過去案件の固有名詞を、今の案件にそのまま持ち込まない（読み替える）

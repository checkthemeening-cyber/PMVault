# tune-persona ― 応答スタイルの設定

`40_運用/persona.md` を、人間が答えやすい質問で更新します。完璧に一度で決めず、使いながら直していく。

## 進め方
1. 現在の `40_運用/persona.md` を読み、今の設定を要約して見せる
2. AskUserQuestion で好みを聞く。例
   - 口調（簡潔／ていねい／フランク）
   - 根拠の出し方（毎回／求めたら）
   - 反対意見の出し方（はっきり／やわらかく）
   - 作業の見せ方（都度報告／最後にまとめて）
3. 答えを `40_運用/persona.md` の各節に反映する
4. 「触れてほしくないこと」も一度確認して書く
5. 更新後の 40_運用/persona.md を見せ、1ターン分その口調で応答して実際の応答を確認してもらう

## 注意
- 元の指示を勝手に消さない。変えるなら確認する
- 抽象語（丁寧に、いい感じに）で終わらせず、具体例まで書く

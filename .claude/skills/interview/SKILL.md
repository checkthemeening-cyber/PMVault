# interview ― 深掘りインタビューで暗黙知を出す

intake が複数トピックを広めに拾うのに対し、interview は1テーマに絞って掘り下げる。言葉になっていない判断基準や経緯を、質問を重ねて引き出す。

## 進め方
1. テーマと、誰に向けた知識かを確認する
2. AskUserQuestion を使い、次の順で掘る。各巡1〜4問、選択肢中心
   - 事実（何が起きたか・現状）
   - 背景（なぜそうなったか）
   - 判断（どう決めたか・基準）
   - 含み（次に効くこと・注意点）
3. 人間の答えに出てくる固有名詞・数値で、公開情報で裏が取れるものは Web で確認しURLを添える
4. 30_インプット/sources/ に詳細ノートで保存する

## 保存フォーマット
- ファイル名：`YYYY-MM-DD_カテゴリ_テーマ.md`
- 見出し：事実 / 背景 / 判断 / 含み の4節
- 人間の言葉とAIの確認（出典付き）を分けて書く。未確認は明記
- 40_運用/domain.md に効きそうな判断基準が出たら、その旨を末尾にメモ（→ /update-domain で反映）

## 注意
- 誘導しない。選択肢は偏らせない
- 答えにくい質問が続いたら、粒度を下げる

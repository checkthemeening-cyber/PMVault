# nikkei-news スクリプト 使用ガイド（改善版）

## 概要

このスクリプトは日経新聞の 5 つのビジネスカテゴリから毎日のニュースを自動収集し、記事本文を含めて Markdown ファイルで保存します。Cookie ベース認証に対応し、有料記事の本文も取得可能です。

## 主な改善

| 項目 | 従来版 | 改善版 |
|---|---|---|
| 記事内容 | 見出しのみ | **見出し + リード + 本文全体** |
| 有料記事 | タイトル表示のみ | **本文も表示（Cookie 認証時）** |
| 認証 | なし | **Cookie ベース認証対応** |
| データ形式 | モックのみ | **リアルデータ + モック併用** |
| 出力品質 | 概要レベル | **詳細分析可能レベル** |

## 前提条件

### システム要件
- Python 3.8 以上
- Windows 10/11（またはMac/Linux）
- インターネット接続

### 日経新聞アカウント
- 日経新聞 Web サイトにログイン可能なアカウント
  - 無料会員・有料会員の両方に対応
  - 無料記事でも本文取得可能
  - 有料記事は Cookie 認証で本文表示

## 使用方法

### morning モード（朝の収集）

**目的**: 当日の全カテゴリ記事を新規取得

```bash
python nikkei-news.py morning
```

**実行内容:**
- 5 カテゴリから当日の全記事を取得
- 各カテゴリごとに 1 ファイル作成
- 記事本文を含めて保存
- 既存ファイルがあれば上書き

**出力例:**
```
[morning] 2026年07月17日 09:50 の収集を開始します
  → 資源エネルギー を収集中...
    保存完了: C:\Users\check\PMVault\00_ナレッジ\nikkei-news\daily\2026\07\17\資源エネルギー.md
  → 建設・不動産 を収集中...
  ...
[morning] 収集完了
```

**出力ファイル:**
```
00_ナレッジ/nikkei-news/daily/2026/07/17/
├── 資源エネルギー.md
├── 建設・不動産.md
├── 物流・運輸.md
├── 商社・卸売り.md
└── 自動車.md
```

**推奨実行時刻**: 朝 6:00 ～ 8:00

---

### evening モード（夕方の追記）

**目的**: morning 実行後の新着記事を追記

```bash
python nikkei-news.py evening
```

**実行内容:**
- morning で取得済みの記事をスキップ
- 新規記事のみを追記
- 「夕刊更新」セクションで分離
- 新着がない場合はその旨を記載

**出力例:**
```
[evening] 2026年07月17日 18:30 の更新を開始します
  → 資源エネルギー の新着を確認中...
    3件の新着を追記: C:\Users\check\PMVault\00_ナレッジ\nikkei-news\daily\2026\07\17\資源エネルギー.md
  ...
[evening] 更新完了
```

**推奨実行時刻**: 夕方 17:00 ～ 19:00

---

### monthly モード（月次サマリ）

**目的**: 前月のニュース月次サマリを作成

```bash
python nikkei-news.py monthly
```

**実行内容:**
- 前月の daily ファイルを集約
- カテゴリ別のハイライトを作成
- Top 5 記事を抽出

**出力ファイル:**
```
00_ナレッジ/nikkei-news/monthly/2026/06_summary.md
```

**推奨実行日**: 毎月 1 日

---

### yearly モード（年次サマリ）

**目的**: 前年のニュース年次サマリを作成

```bash
python nikkei-news.py yearly
```

**実行内容:**
- 前年の monthly ファイルを集約
- 年間のキーハイライトを作成
- Top 10 記事を抽出

**出力ファイル:**
```
00_ナレッジ/nikkei-news/yearly/2025_summary.md
```

**推奨実行日**: 1 月 1 日

**収集記事数**: 5件（当日分）

### 記事情報の構成

各記事は以下の要素を含みます：

| 要素 | 内容 | 備考 |
|---|---|---|
| タイトル | 記事見出し | H3 ヘッダー |
| 公開日時 | 日付 + 時刻 | JST 形式 |
| URL | 記事リンク | クリック可能 |
| リード文 | 要約（50 字程度） | `>` ブロック引用 |
| 本文 | 全体テキスト | 段落で分割 |
| 有料表示 | 【有料記事】フラグ | 認証時のみ |

## Cookie 認証について

### Cookie が読み込まれた場合
```
**認証**: Cookie 認証有効
```
- 有料記事の本文が取得される
- 記事詳細ページへのアクセスが可能
- より詳細な本文情報が含まれる

### Cookie が読み込まれない場合
```
**認証**: Cookie なし（モック表示）
```
- モックデータで動作
- 本文は仮データ（実データではない）
- 動作確認・テスト用途に最適

## トラブルシューティング

### エラー: Cookie ファイルが見つからない

```
警告: Cookie ファイルが見つかりません: C:\Users\check\PMVault\.claude\scripts\nikkei-cookies.txt
```

**解決策:**
- Cookie ファイルは optional（ない場合はモック実行）
- 実データを取得する場合のみファイルを作成
- `NIKKEI_COOKIE_SETUP.md` の手順を確認

### エラー: ファイル保存に失敗

```
OSError: [Errno 2] No such file or directory
```

**解決策:**
- `00_ナレッジ/nikkei-news/daily/YYYY/MM/DD/` ディレクトリが自動作成されない場合
- 手動でディレクトリを作成してから実行
- または、一度 morning モードを実行してディレクトリを作成

### HTML パースエラー

```
HTML パースエラー: ...
```

**解決策:**
- 日経新聞の HTML 構造が変更された可能性
- スクリプトのセレクタを確認・更新が必要
- `HTMLArticleParser` クラスを修正

## FAQ

### Q: Cookie なしでも動作しますか？
**A**: はい。モックデータで全機能を確認できます。本文は仮データですが、フォーマットは実データと同じです。

### Q: 複数カテゴリを同時に処理できますか？
**A**: 現在は順序実行です。並行実行が必要な場合は、スクリプトを複数起動してください。

### Q: 記事本文の取得に失敗する場合は？
**A**: 日経新聞の HTML 構造が変更された可能性があります。`HTMLArticleParser` のセレクタを確認してください。

### Q: 出力ファイルはどこに保存されますか？
**A**: `C:\Users\check\PMVault\00_ナレッジ\nikkei-news\` ディレクトリ配下の日付別フォルダです。

### Q: 過去の記事も取得できますか？
**A**: 現在は当日分のみです。過去記事対応は将来の拡張予定です。

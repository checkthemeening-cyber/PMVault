# benchmarks ― 数字の引き出し

再利用する数値そのものを1件1エントリで貯める場所です。事例カードや業界KPIとは別物で、提案や市場規模の推計で即座に引く生の数字を置きます。

## 何を置くか（cases / industries との違い）
- benchmarks … 再利用する数値（粗利率の相場、CACペイバック月数、業界成長率、買収マルチプル）
- cases … 企業の取り組み事例（課題→施策→効果）
- industries … 指標の定義と業界プロファイル

## 何を必ず持たせるか
[[_templates/ベンチマーク_テンプレ]] から作り、frontmatter に 数値・単位・対象範囲・一次URL・取得日・certainty を入れます。対象範囲（いつの、どの市場の、どの企業群の数字か）を欠くと、後で誤用します。

## 数字の鮮度管理
数字は他のノートより早く陳腐化します。certainty と last_verified を必ず付け、古いものは再取得対象として明示します。価格やコンプラ系は即時で陳腐化、業界相場は四半期から年単位で見直す前提です。信頼レイヤーの考え方は [[00_ナレッジ/concepts/共有の第二の脳]] を参照。

## 引き出し方の例
- 「SaaSの粗利率の相場は」→ topic=SaaS かつ type=ベンチマーク で絞る
- last_verified が古いものは『要再取得』として扱う

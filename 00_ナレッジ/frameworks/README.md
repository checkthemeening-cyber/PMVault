# frameworks ― 分析フレームワーク・ライブラリ

何を分析するかの型を1枚1フレームで貯める場所です。提案ストーリーの型（伝え方）とは別物で、こちらは中身を作る道具箱です。伝え方の型は [[00_ナレッジ/concepts/提案ストーリーの型]] にあります。

## 何を置くか
1フレーム1ノート。常設ページとして 00_ナレッジ/concepts/ と同じ運用で追加・更新していく。

- 古典：Porter 5 Forces / 3C / PEST / SWOT / バリューチェーン / BCGマトリクス / 7S / TAM SAM SOM / シナリオプランニング / JTBD
- 案件で繰り返し使うものから先に作る。全部を埋める必要はない

## 使い方
案件着手時に「この案件にどのフレームが効くか」を index 経由で絞り込む。各フレームは入力と出力が決まっているので、手元のデータをどのフレームに渡すか即判断できる。

## 新規フレーム
[[_templates/フレームワーク_テンプレ]] から作り、index.md の『フレームワーク（00_ナレッジ/frameworks/）』に1行追加。見本は [[3C分析]]。

## 落とし穴を必ず書く
フレームを当てはめただけでは、分析は終わっていません。各ノートの「落とし穴」欄に、向かない場面と誤用パターンを残してください。型に振り回されないための歯止めになります。

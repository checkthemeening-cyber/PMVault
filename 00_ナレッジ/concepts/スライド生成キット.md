# スライド生成キット

要約：`スライド生成/` にあるADL品質スライド生成キット4種の使い分け。**どのキットを使う場合も、様式の正典は [[ADLスライド様式]]**（公式ガイドライン由来）であり、キット内の定義値と食い違う場合は公式を優先する。

## 4方式の使い分け
| キット | 出力 | 仕組み | 選ぶ基準 |
|---|---|---|---|
| `adl-deck-kit-v3` | 編集可能pptx | テンプレ原本から抜いた台紙 `ADL_Base.pptx` の26レイアウトから python-pptx で直接生やす | **テンプレ準拠を厳密に求めるとき、または納品物並みの密度（1ページ400〜900字・図表2〜5個）が要るとき**。ロゴ・配色・書体・ページ番号がマスターから自動で入るため崩れようがない |
| `adl-slide-kit` | 編集可能pptx + HTML | AIは内容YAMLだけ書き、Pythonコンパイラがレイアウトを決定論的に生成 | 品質がモデル能力に左右されないことを優先するとき。pptx納品が要るとき |
| `adl-html-kit` | 単一HTML | AIがHTMLを直接生成。レイアウト自由度が最大（パターン102種） | 環境構築なしでブラウザ投影したいとき。pptxが不要なとき |
| `adl-pptmaster-kit` | 編集可能pptx | AIが1ページずつSVGを描き `vendor/svg_to_pptx.py` で変換 | 自由レイアウト×pptx納品を両立したいとき。高性能モデル向け。テンプレのマスター・レイアウトは通らないため「似ているが準拠していない」出力になりやすい点に注意 |

いずれもフォルダ単位で自己完結。各キットの `CLAUDE.md` と `AI_GUIDE.md` に作業指示、`guide/index.html` に使い方がある（`adl-deck-kit-v3` は `SKILL.md` と `CLAUDE.md` が入口）。

`adl-deck-kit-v3` はユーザー設定Skill `adl-deck-v3`（`C:\Users\check\.claude\skills\adl-deck-v3\SKILL.md`）として登録済み。既存のユーザー設定Skill `adl-slide` は `adl-pptmaster-kit`（SVG→pptx方式）を使う。トリガー語が重なる依頼が来た場合は、テンプレ準拠の厳密さが必要なら `adl-deck-v3` を優先する。

## adl-slide-kit（コンパイラ方式）
- 初回のみ `pip install -r requirements.txt`（Python 3.10+）
- 実行：`python3 -m compiler.compile <deck.yaml> --out-dir <出力先> --pptx --html`
- パターン16種：`cover` `agenda` `divider` `gov_bullets` `gov_two_col_detail` `comparison_table` `matrix_chevron` `cards` `roadmap_chevron` `closing` `bar_chart` `hbar_compare` `quadrant_map` `kpi_three` `three_tier_grid` `key_message`
- `compiler/lint.py` が規律を機械検査し、違反するとコンパイルが止まる（ガバニングメッセージの体言止め、色記号に対する凡例欠落、数値に対する出所欠落、枠からのはみ出し等）
- 見本：`samples/demo_10p.yaml`（10枚）、`samples/reference_80p.yaml`（80枚の調査報告書）
- **AIがSVG/HTMLを直接書かない。`compiler/` のコードを書き換えない**

## adl-html-kit（HTML方式）
- デザインシステム定義は `SLIDE-md/SLIDE-md-adl/SLIDE.md`（配色・判組み・情報密度規律・80/10/10）
- レイアウトは `SLIDE-PATTERN/` に102種。`SLIDE-PATTERN-INDEX.md` から13カテゴリで選ぶ
- Claude Code用スキル3種（`slide-deck-builder` / `slide-md-creator` / `slide-pattern-creator`）を同梱
- 生成後にブラウザで実表示確認し、はみ出し・必須要素の欠落を自分で点検する

## adl-pptmaster-kit（SVG→pptx方式）
- SVG生成仕様の正典は `ADL_BRAND_SVG_SPEC.md`
- 1ページ = `NN_slug.svg`（`viewBox="0 0 1280 720"`）を `svg_output/` に置く
- 変換：`python3 vendor/svg_to_pptx.py <svg_outputの親> -o <出力.pptx> -f ppt169 --only native`
- **変換ログの `skipped 0` / `Failed: 0` を必ず確認**。skipが出たら禁止要素の混入
- SVG禁止要素：`mask` / `style`・`class`属性 / `@font-face` / `foreignObject` / `textPath` / `animate` / `script` / 複雑な`filter` / 画像以外の`clipPath`。スタイルは全て属性指定

## 3キット共通の内容規律
- **ガバニングメッセージ**：全本文スライドに、主語＋述語の完全文でSo-Whatまで断言する見出しを置く。体言止め禁止。40〜60字目安。キーワードは Accent 1 の太字
- **箇条書きは2階層**：太字の主張ラベル＋根拠2点。フラットな3項目の垂れ流しで終わらせない
- **80/10/10**：AIが8割を書き、裏取りできない数値は創作せず `ph_review`（マゼンタ付箋＝人間に確認依頼）へ1割、描けない図は `ph_image`（グレー破線枠＋何を/なぜ/推奨作図法）へ1割
- 色記号を使ったら凡例、数値を使ったら出所（左下）、ページ番号（右下）
- **数値・出典・固有名詞を創作しない**。絵文字と信号色（赤緑黄）を使わない

## 注意

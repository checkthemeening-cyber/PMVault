# plays ― 進め方プレイブック

案件をどう回すかの手順を貯める場所です。何を分析するか（[[00_ナレッジ/frameworks/README]]）とは別で、こちらは段取りの型を置きます。

## 何を置くか
1プレイ1ノート。反復する案件の進め方をレシピにします。

- 診断の進め方
- 市場規模の推計レシピ
- 技術デューデリのチェックリスト
- ワークショップ設計
- インタビュー設計（一次情報の取り方）

## 使い方
案件型が反復するコンサルでは、案件横断で効果が出やすい再利用資産です。新しい案件で「どう進めるか」を毎回ゼロから考えず、近いプレイを開いて手順を写し、案件固有の差分だけ埋めます。

## 新規プレイ
[[_templates/プレイブック_テンプレ]] から作り、index.md の『プレイブック（00_ナレッジ/plays/）』に1行追加。各プレイには「つまずき」を記録し、次回の参照点にします。

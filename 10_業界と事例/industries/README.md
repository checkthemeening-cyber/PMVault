# industries ― 業界プロファイル置き場

1業界1ファイル。固定見出し（論点／KPI／規制・ガイダンス／代表的取り組み／最新動向）で横並び比較できる常設ページ。

使い方：案件着手時にまず該当業界ノートを開く。事例は 10_業界と事例/cases/、動向は 10_業界と事例/trends/ から相互リンクで辿る。

新規業界は [[業界プロファイル_テンプレ]] から作り、index.md の『ドメイン別サブ索引』に1行追加する。

収録：[[製造業]] / [[金融]] / [[小売・流通]] / [[ヘルスケア・製薬]] / [[エネルギー・電力]] / [[公共・行政]] / [[通信]]

> KPIは実測値＋出典URL（日付）で書く。一次か二次かを書き分け、二次のみは『要一次裏取り』を付ける（ADL規約）。

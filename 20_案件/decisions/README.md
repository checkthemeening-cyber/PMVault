# decisions ― 論点・前提・決定ログ

案件で走り続ける論点（イシュー）と前提（assumptions）、そして確定した意思決定を追跡する場所です。仮説の立て方は [[00_ナレッジ/concepts/仮説思考とストーリーライン]]、ここで追跡します。

## 2種類を分けて持つ
- 論点と前提（生きているレジスタ）… 案件ごとに `20_案件/engagements/<案件名>/論点と前提.md` に置く。更新し続ける
- 意思決定ログ（確定した決定）… 1決定1ノート。[[_templates/意思決定ログ_テンプレ]] から作る

## 論点と前提レジスタに入れるもの
- 論点：今この案件で答えを出すべき問い
- 現時点の仮説：その論点への暫定回答
- 前提：仮説が成り立つために真であるべきこと
- 未決事項：まだ答えが出ていないこと

## 前提には鮮度を付ける
前提には certainty と last_verified を必ず付けます。前提が古いまま放置されると、Claude Code が無効な前提に基づいて回答し、無効な前提をそのまま根拠に使うリスクがあります。

- certainty：確実 / 有力 / 仮説 / 未確認
- last_verified：最後に人手で確認した日

確認が取れていない前提は『未確認』のまま置き、決定の根拠に使う前に裏を取ります。鮮度足切りの考え方は [[00_ナレッジ/concepts/共有の第二の脳]] を参照。

## 決定が確定したら
[[_templates/意思決定ログ_テンプレ]] で1枚作り、決定・理由・却下案・決めた人・日付を残します。根拠にした論点へリンクで戻せるようにします。
